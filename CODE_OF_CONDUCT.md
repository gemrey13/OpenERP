# Code of Conduct

## Our Commitment

OpenERP is an open-source project that aims to provide a welcoming, respectful, and collaborative environment for everyone who participates.

We expect all contributors and community members to behave professionally and respectfully.

## Expected Behavior

Examples of positive behavior include:

* Being respectful and constructive
* Welcoming people with different levels of experience
* Providing useful and respectful feedback
* Accepting constructive criticism
* Focusing on technical issues rather than individuals
* Giving credit where it is due
* Helping other contributors learn
* Respecting different opinions and approaches

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or discrimination
* Personal attacks
* Trolling or deliberate disruption
* Threats or intimidation
* Sexual harassment
* Publishing someone's private information without permission
* Insulting or degrading comments
* Deliberately interfering with project discussions
* Any other behavior that would reasonably be considered inappropriate in a professional community

## Reporting Problems

If you experience or witness unacceptable behavior, please report it privately to the project maintainers.

When making a report, provide as much relevant information as possible, including:

* What happened
* When it happened
* Where it happened
* People involved
* Any relevant screenshots or other evidence

Reports will be reviewed by the project maintainers.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions include:

* A warning
* Removal of inappropriate content
* Temporary restriction from project participation
* Permanent removal from the project

The response will depend on the severity and circumstances of the violation.

## Scope

This Code of Conduct applies to project spaces, including:

* GitHub issues
* Pull requests
* Discussions
* Code reviews
* Project communication channels
* Other spaces where participants represent the OpenERP project
